# CareerTrack

CareerTrack is a full-stack student career and application tracking system designed to help students manage their job applications, internships, exams, and important career-related notifications in one place.

## Features

- Track job and internship applications
- Store application details and status
- Manage interview dates and schedules
- Track exams such as GATE and CAT
- Dashboard for monitoring career activities
- Organize important career-related information
- Simple and user-friendly interface

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Vite

### Backend
- Java
- Spring Boot
- REST APIs

### Database
- MongoDB

## Project Structure

The project consists of a React frontend and a Spring Boot backend connected through REST APIs.

## Future Enhancements

- AI-based email parsing
- Automatic detection of interview dates and application status
- Career and internship notifications
- GATE and other exam notifications
- Job recommendation system
- Email integration

## Purpose

CareerTrack aims to provide students with a centralized platform to manage their career journey, from discovering opportunities to tracking applications, interviews, and examinations.
